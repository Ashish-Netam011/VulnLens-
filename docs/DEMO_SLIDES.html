Key Features

What VulnLens ships today.

🔍

8 Vulnerability Families

SQL injection, XSS, hardcoded secrets, weak crypto, dangerous functions, misconfig, sensitive data, file handling.

🔀

Data Flow Analysis

Source-to-sink taint tracing. Shows the exact attack path an exploiter would use.

🤖

AI Copilot

Per-finding explanations, impact analysis, and secure code fixes. Advisory only — never decides.

🔄

Rescan Verification

Stable comparison keys classify findings as resolved, remaining, or new after fixes.

🚨

CI Security Gate

Baseline-aware regression. New HIGH findings fail CI. Baselined findings stay visible.

📋

SARIF 2.1.0 Export

Standard format for GitHub Code Scanning and any SARIF-compatible tooling.
